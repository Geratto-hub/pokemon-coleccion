# Colección Pokémon TCG

Web para llevar el recuento de mis cartas Pokémon: las que tengo, las que me faltan y su precio estimado (Cardmarket, vía TCGdex).

- Datos de cartas y precios: [TCGdex](https://tcgdex.dev) (gratis, sin clave)
- Base de datos e inicio de sesión: Supabase (plan gratuito)
- Alojamiento: GitHub Pages
